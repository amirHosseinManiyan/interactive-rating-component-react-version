# Interactive Rating Component — React

A responsive and interactive rating component built with React. Users can select a rating from 1 to 5 and submit their feedback to view a thank-you screen.

This is the second version of the project, rebuilt with React. The original version was developed using vanilla JavaScript.

## Live Demo

[View Live Demo](https://amirhosseinmaniyan.github.io/interactive-rating-component-react-version/)

## Previous Version

The original version was built using HTML, CSS, and vanilla JavaScript.

[View Vanilla JavaScript Version](https://github.com/amirHosseinManiyan/interactive-rating-component-project)

## Features

- Select a rating from 1 to 5.
- Submit the selected rating and display a confirmation screen.
- Interactive rating selection with visual feedback.
- Responsive design for mobile and desktop screens.

## Built With

- React
- JavaScript (ES6+)
- CSS
- Vite

## What I Learned

- Managing component state with React Hooks.
- Handling user interactions with event handlers.

- Breaking the interface into React components.
- Applying responsive design principles with CSS.

## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/amirHosseinManiyan/interactive-rating-component-react-version.git
   ```

2. Navigate to the project directory:

   ```bash
   cd interactive-rating-component-react-version
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
